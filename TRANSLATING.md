# Translating qUnleashed

Translations are managed on [Crowdin](https://crowdin.com/). English is the only
source language; every other language is written on Crowdin and lands in this
repository through a pull request.

## For translators

Join the Crowdin project and translate there. Nothing has to be done in git.
Two kinds of content are open for translation:

- **App strings** — the interface of the app itself.
- **Store listing** — the short and full Google Play descriptions and the
  release changelogs.

The app name (`qUnleashed`) and the promo video URL are not translated.

## For maintainers

### Adding a string

Add the key and an `@`-description to `translations/app_en.arb` only. The
description is what translators read for context, so say where the string
appears and what the placeholders mean. Never edit `app_ru.arb` or any other
translation by hand — Crowdin overwrites them.

```json
"deviceDisconnected": "Device disconnected",
"@deviceDisconnected": {
  "description": "Shown on the device screen when the link to the Flipper drops."
}
```

### Using a string

Widgets read strings from the `BuildContext`:

```dart
import '../../services/localization/l10n.dart';

Text(context.l10n.deviceDisconnected)
```

Services, controllers and enum labels have no context and use the global
accessor, which resolves against the same locale as the widget tree:

```dart
import '../services/localization/l10n.dart';

final message = l10n.deviceDisconnected;
```

### Adding a language

1. Add the locale to `_localeNames` in `lib/services/localization/controller.dart`,
   with the
   language name written in that language.
2. Enable the language in the Crowdin project.

`supportedLocales` follows the `.arb` files on disk, so the language appears in
the picker as soon as Crowdin delivers its `app_<code>.arb`.

### Generated code

`lib/services/localization/gen/` is generated by `flutter gen-l10n` from the
`.arb` files in `translations/` and is not committed. Builds regenerate it automatically (`generate: true` in
`pubspec.yaml`); run `flutter gen-l10n` by hand after editing an `.arb` if the
IDE has not caught up.

### Sync

`.github/workflows/crowdin.yml` uploads sources when they change on `main`, and
opens a `New translations from Crowdin` pull request daily and on demand. It
needs two repository secrets: `CROWDIN_PROJECT_ID` and `CROWDIN_PERSONAL_TOKEN`.
