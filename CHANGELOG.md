## Main changes
- Version: 0.17.1
- Archive: **A bulk delete no longer half-applies** - a link that was down skipped the device half in silence, removed the local copy anyway and reported success, so the next sync pulled the file straight back; each key is now all of it or none of it, the wait is held open for a link that is settling, and a refused restore or save is recorded rather than only shown (by @mishamyte | PR #399 | Closes #373, #374)
## Other changes
- Connection: Stop telling people to toggle their Flipper when it is their phone that failed - the Android Bluetooth plugin throws an internal error out of an automatic reconnect, and because nothing recognised that string the app fell back to its catch-all advice: turn Bluetooth off and on in the device system menu. That fault has nothing to do with the Flipper, the range or any setting, and there is nothing in a menu to change; it now has a message of its own saying so, the same one whether the link is Bluetooth or a cable, and it is still reported so the underlying plugin bug stays visible (by @mishamyte | PR #437)
- Windows: Put the app folder where Windows actually keeps Documents - the location was assumed to be the Documents folder directly under the user profile, so on a machine where OneDrive Known Folder Move had redirected it, or where it had been moved to another drive by hand, that folder could not be created and nothing that keeps a file worked: the archive, the IR library, screenshots and recordings all hang off that one path. The location now comes from the operating system, which is the only answer that follows a redirect, and the old guess stays as the fallback (by @mishamyte | PR #435)
- Android: Put the home screen widget's text through Crowdin - its ten strings sat in Android resource files the translation pipeline never saw, so the app was translated and the widget beside it was English in every language but Russian, whose one translation was written by hand and spelled the product's name in Cyrillic against the project's own rule; the strings are now ten keys in `translations/app_en.arb` like the other 1446 and the Android resources are generated from whatever Crowdin has sent back, so each language reaches the widget as it is translated and enabling the next one needs no change under `android/` (by @mishamyte | PR #431 | Closes #319)
- Device: Keep the bottom bar's device label readable rather than cut - the four tabs split the screen equally, so the label gets 74 points on a common phone, and a device state longer than that was clipped with an ellipsis; since the states share their first several characters, what was left on screen was the same word for two different states - "Syncing" and "Synced" in three languages on a small phone and in all eight at a raised system font size, "Connecting" and "Connected" in all eight including English. The label now shrinks to fit the room it has, down to a floor, and is cut only once there is nothing left to shrink; of the 28 pairs the eight states make, 20 could be read as each other somewhere and none can now (by @mishamyte | PR #430 | Closes #425)
- Device: Stop the device screen's Full Info button painting over the Flipper's UID - the button floated over the header rather than taking a place in it, and an overlap is not reported the way an overflow is, so on a tablet or a narrow desktop window the UID line simply lost its tail underneath the button, in every language; the button sits under the hero where the screen is too narrow to hold both and beside it where it is not, so the line is whole where it has the room and ellipsised where it does not (by @mishamyte | PR #427 | Closes #417)
- Device: Say "Synced" on the bottom bar once the archive has finished syncing - the label was written and translated into seven languages, but the condition in front of it read a device flag that is always set by then, so a completed sync read "Connected" like any other connected Flipper; the word now means what it says, so it is dropped when another Flipper takes over the connection, and one category's refresh no longer claims the whole archive is in step (by @mishamyte | PR #424 | Closes #420)
- Device: Stop the device screen clipping the Flipper's name - the header's text had no room of its own, so a name too long for a phone was cut off at the edge of the screen, and at a larger system font size the header spilled over the list below it; the text wraps or ellipsises now and the header is as tall as whatever it is showing rather than as tall as a number the page picked (by @mishamyte | PR #418 | Closes #411)
- Archive: Stop the whole app rebuilding on every archive notification - a sync notified the shell four times per file it downloaded and each one re-ran the build of every tab left open behind it; the bottom bar now follows the one value it takes from the archive, so a two-thousand-file sync redraws it three times rather than eight thousand (by @mishamyte | PR #416 | Closes #410)
- Device: Stop the whole app rebuilding on the five-second device poll - the shell was subscribed for one label in the bottom bar, which a desktop window does not even draw, and was rebuilding every open tab to redraw it (by @mishamyte | PR #412 | Closes #407)
- Device: Read the device client without subscribing to the device - thirty call sites across eighteen files stop rebuilding on the five-second info poll, and one tap on a firmware changelog stops subscribing the device screen for the rest of the session (by @mishamyte | PR #406 | Closes #344)
- Quality: The archive's four copies of multi-select became one mixin, and its category, deleted and favourites screens - which were one screen written three times - became one frame; a ratchet holds the first (by @mishamyte | PR #403, #405 | Closes #375, #376, #404)
