## Main changes
- Version: 0.17.2
## Other changes
- Fixed: if the saved list of your remembered Flippers was ever replaced by something the app could not read as a list - a restored backup, or a file written by a newer version - the whole list was emptied without a word, which also left Bluetooth auto-connect with nothing to dial, and the next connection saved the empty list over it for good; the app now records what it found, and a single damaged entry costs that entry instead of every remembered device (by @mishamyte | PR #484 | Fixes #466)
- Fixed: running out of disk space while the Assembler downloaded the Flipper SDK or toolchain crashed the app and left the job spinning until it was restarted, with nothing on the console to say what had happened; the failure is now reported where the download was started, names the file and the reason, and the part-written file is discarded instead of being left on the disk that had just filled up (by @mishamyte | PR #483 | Fixes #482)
- Fixed: on a wide window the device header drew the Flipper mockup flush against the top and bottom edges of the coloured band, with no room left around it; the spacing is back, and it is now a value of its own rather than the leftover of a header height that was removed two releases ago (by @mishamyte | PR #481 | Fixes #480)
- Fixed: at a raised text-size setting the firmware card's "Update Channel" and "Build Variant" labels were drawn one character per line, as a column of letters that pushed the update button off the screen; a label and its value now share a line only while both fit it whole, and the label moves above the value instead of being squeezed (by @mishamyte | PR #473 | Fixes #463)
- Interface: the device tab now reads "Device" with a coloured dot on its icon for the connection state, instead of fitting a status sentence into a quarter of the bar - which ignored a raised text-size setting in every locale and drew two different sync states as the same cut-down word; the state is still announced in full to screen readers (by @mishamyte | PR #462 | Closes #429)
- Fixed: a Flipper terminal whose connection dropped while the cable stayed plugged in was never reopened, and the app dialled Bluetooth instead while the CLI page waited for a channel that was not coming back (by @mishamyte | PR #464 | Fixes #461)
- Fixed: a USB Flipper the app had connected to on its own kept being reconnected after USB auto-connect was turned off in Settings, because a link the app dialled itself was treated as one the user had asked for (by @mishamyte | PR #464 | Fixes #460)
- Changed: the app now connects to a Flipper that is plugged in with a cable instead of reaching for the last remembered Bluetooth device, so launching with the cable already in no longer brings the session up over Bluetooth; USB auto-connect is on by default, and turning it off in Settings restores the old behaviour (by @mishamyte | PR #458 | Fixes #454)
- Changed: this release moves to a newer Bluetooth library, which writes device addresses in a different case than the one your remembered Flipper was saved under; the saved address is carried over as soon as the app reads it, so the device list and auto-connect carry on working (by @mishamyte | PR #450 | Fixes #444)
- Fixed: on Linux the app filed a crash report at every launch on a machine with no Bluetooth stack installed, and left Bluetooth dead for the rest of the session even after the stack was installed; it now checks whether the system can bring BlueZ up before asking it to, and installing `bluez` is noticed on the next scan (by @mishamyte | PR #449 | Fixes #443)
- Fixed: an icon the renderer could not draw left an empty box and filed a crash report for every icon on screen, sixteen in one second on a cold start; the failure is now kept once, and a missing asset is told apart from a surface the engine refused (by @mishamyte | PR #448 | Fixes #441)
- Fixed: declining notification permission turned every disconnect into a crash report on iOS, because the app asked the system to post one anyway and never kept the answer it had already been given (by @mishamyte | PR #448 | Fixes #442)
