## Main changes
- Version: 0.17.0
- Localization: translated app to Belarusian, Croatian, French, German and Spanish (by @mishamyte | PR #320, #323)
- Notifications: keep push alive through the APNS token race, and stop pretending macOS has push (by @mishamyte | PR #325 | Closes #324)
- Diagnostics: **Screen replays show the interface again** - the SDK's blanket text mask was greying out every button, tab and title, so a recording of a failure showed nothing anybody could read (by @mishamyte | PR #334 | Closes #331)
- Settings: a setting that does not persist is recorded instead of lost in silence, and the home-screen widget stops showing a look that was never saved (by @mishamyte | PR #335 | Closes #313)
- Permissions: **a denied permission now says so, in the place it matters** - refusing storage used to leave the infrared page offering to re-download a library that was already on disk and Settings -> Storage reporting 0 B, refusing Bluetooth said "No devices found." and blamed the hardware, and refusing notifications was reported as an unsigned build; each one now names what is out of reach, what still works, and offers the way to fix it, and clears itself when you come back from system settings (by @mishamyte | PR #358, #350 | Closes #351)
## Other changes
- Archive: a bulk action you walk away from no longer ends as a crash report - restoring, deleting, starring or saving a selection clears that selection when it finishes, and clearing it on a page that is already gone threw, which in a release build is a fatal error nobody sees and nothing retries (by @mishamyte | PR #369)
- Devices: a Flipper at the edge of its range is told apart from one that refused the connection - a link that came up and died a second later read as a generic "connection failed", and a remembered device that had just proved unreachable kept showing its "in reach" dot (by @mishamyte | PR #367 | Closes #363)
- Interface: long translations no longer clip or push a row off the screen - the Apps catalog header ran 140 pixels past the edge in French, every catalog button cut "Installieren" to "Installie", five to seven archive action labels per language were cut mid-word, and German’s "Verbindung wird hergestellt" pushed the bottom bar off the screen (by @mishamyte | PR #364)
- Flibler: a build or a checkout that fails now says what it was doing - which tool, the exit code, the folder it ran in and the full command - instead of a bare "failed with exit code 1" that named neither the file nor anything to try, and a tool that fails without printing anything says that too (by @mishamyte | PR #356 | Closes #355)
- Tools: MIFARE key recovery leaves beta - the attack set is complete, it works on all six platforms, and every fault filed against it is fixed, so the tools list no longer marks it Beta (by @mishamyte | PR #349 | Closes #348)
- Diagnostics: a connect attempt that fails is now counted in the reports sent to the developers - which kind of failure it was, over Bluetooth or USB, and whether the app or you started it - and a message nothing recognises is reported in full, so the next build can name it instead of showing a generic sentence (by @mishamyte | PR #347)
- Tools: MIFARE key recovery no longer stalls for seconds at a time while a hardnested attack runs, and the recovered key list now follows a language or theme change (by @mishamyte | PR #346)
- Archive: choosing a file the system picker cannot hand over no longer kills the app - uploading from the file browser died behind the open dialog, and a refused folder picker could do the same on desktop from the archive's bulk save, the Flibler folder picker and Pixel Draw's export (by @mishamyte | PR #352)
- Tools: picking a large file in the pulse plotter or Pixel Draw no longer kills the app, and one too big to import says so instead (by @mishamyte | PR #345)
- Archive: stop a right click in the text editor crashing the frame on every desktop target (by @mishamyte | PR #329 | Closes #328)
- Translations: Stop the Crowdin sync opening an empty pull request every night (by @mishamyte | PR #327 | Closes #326)
- Fixed: a push topic call that failed while offline uploaded a full session replay from every iOS launch, instead of the buffered minute before a failure (by @mishamyte | PR #334 | Closes #332)
- Diagnostics: device names, serials, BLE addresses and card identifiers are no longer replaced with placeholders in the reports sent to the developers, so a report says which unit and which card it is about (by @mishamyte | PR #334)
- Crash reports: an Android crash in Java or Kotlin code now names real classes and methods instead of the shrinker's `w2.r.k`, so a report can be read without guessing what it came from (by @mishamyte | PR #360 | Closes #343)
- Crash reports: Windows and Linux builds carry debug information now, so a native crash names the function and line instead of the nearest export (by @mishamyte | PR #330 | Closes #310)
- Fixed: MIFARE and SubGHz seed recovery on Linux, where the three native libraries were never copied into the release bundle and every attempt failed to load them (by @mishamyte | PR #330 | Closes #338)
- Apps: stop a text selection in an app's description or changelog crashing the app when its handle is dragged, and stop the detail page redoing its markdown twelve times a minute (by @mishamyte | PR #339)
- Localization: a device set to a language the app does not speak now opens in English, instead of whichever language sorts first - a phone set to Japanese came up in Belarusian, and so did every notice raised by a service with no screen behind it (by @mishamyte | PR #322)
